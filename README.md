# OBD Master

**Diagnóstico y codificación de vehículos · Multimarca · Windows**

OBD Master es una aplicación profesional de diagnóstico y codificación para
automóviles, compatible con adaptadores **ELM327** (USB / Bluetooth / Wi-Fi) e
interfaces **J2534**.

## ⬇️ Descargar

Descarga la última versión desde **[Releases](https://github.com/Rannden-SHA/OBD-Master/releases/latest)**:

- `OBD-Master-Setup-X.Y.Z.exe` — instalador para Windows.

La aplicación se **actualiza sola**: te avisa cuando hay una versión nueva.

## ✨ Funciones

- Lectura y borrado de códigos de avería (DTC) con base de datos en español.
- Datos en vivo, indicadores, gráficas y **osciloscopio**.
- **Escaneo** completo de centralitas (Auto Scan).
- **Codificación** y adaptaciones, **pruebas de actuadores**.
- **Modo mecánico**: causas, síntomas y reparación guiada de cada avería.
- **Taller**: historial de reparaciones y plan de mantenimiento por marca.
- Consola **UDS** experta (ISO 14229), **monitor CAN** e informes de salud en PDF.
- Multimarca: +27 fabricantes, incluidos eléctricos modernos.
